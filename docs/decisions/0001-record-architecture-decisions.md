# 0001 — Record architecture decisions

**Status:** accepted · **Date:** 2026-09-04

## Context

Decisions made in chat are lost between sessions and get re-argued, which costs
time and tokens and produces drift.

## Decision

Every non-obvious decision gets a short file here: context, decision,
consequences. Superseded records are marked, never deleted — the reasoning
behind a reversal is worth as much as the reversal.

## Consequences

A decision is read once instead of re-derived. New sessions can reconstruct
*why* the system looks the way it does without asking.
